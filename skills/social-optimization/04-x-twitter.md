# X (Twitter) optimization

## Do first
1. Display name — drop persona nicknames/jokes that don't signal professional identity to a stranger scanning the timeline (a private joke reads as noise to someone deciding whether to follow/hire).
2. Bio — lead with what the person builds/does professionally, current company/studio, core stack, then a link. A single personal-values line (faith, motto, etc.) can stay if the person wants it, but it should not be the *first* thing read, and it should not crowd out the professional signal entirely.
3. Profile photo and banner — X profiles with neither set read as abandoned/inactive accounts to a visitor, regardless of how much real posting history exists underneath. This is often the single highest-leverage, lowest-effort fix on X.

## Tone calibration
- Ask (or infer from Phase 0 research) how much personality/humor the person wants to keep. The right calibration is usually "keep the voice, but what I build should register before any joke or persona bit" — not a full corporate rebrand unless the person explicitly wants that.
- If the person already posts build-in-public style content, that's a real asset — don't recommend replacing their existing voice, just make sure the static profile fields (name/bio/photo/banner) match the quality bar of the content they're already posting.

## What NOT to do
- Don't invent a new posting style or content calendar unless asked — this skill covers the static profile, not a content strategy engagement.
- Don't strip out every trace of personality in the name of "professionalism" — a flat, generic bio is also a failure mode, just a different one from an unprofessional one.
